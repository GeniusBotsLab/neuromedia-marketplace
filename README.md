# Neuromedia — AI Marketplace

[English](docs/README.en.md) · [Каталог](content/catalog/catalog.ru.json) · [Сайт](https://neuromedia.cloud/)

**Neuromedia** — AI-маркетплейс решений, агентов, API и инфраструктуры для бизнеса. Платформа помогает подобрать готовый AI-инструмент или услугу под практическую задачу: продажи, поддержка, контент, документы, автоматизация и production-запуск.

> Это публичная витрина проекта, а не исходный код магазина. Актуальный ассортимент и оформление заказа доступны на [neuromedia.cloud](https://neuromedia.cloud/).

## Что доступно

- **AI API и модели** — доступы для продуктов, ботов, CRM и внутренних сервисов.
- **AI-агенты** — помощники для продаж, поддержки, контента и операционных процессов.
- **Автоматизация** — workflow для лидов, документов, таблиц, CRM и back-office.
- **Генерация медиа** — изображения, видео и контентные AI-процессы.
- **AI-инфраструктура** — inference, вычислительные ресурсы и production-контур.
- **Экспертные услуги** — внедрение, настройка и адаптация решений под бизнес-задачу.

## Как работает маркетплейс

1. Выберите направление или конкретное решение в [каталоге магазина](https://neuromedia.cloud/).
2. Оцените описание, формат доступа, актуальную стоимость и статус наличия.
3. Оформите заказ на сайте; для поддерживаемых сценариев доступна **оплата криптовалютой**.
4. Получите цифровой доступ, услугу или сопровождение в соответствии с условиями выбранного предложения.

## Контент и обновления

Neuromedia развивает не только каталог: на платформе доступны **статьи, гайды, новости и кейсы** о прикладном использовании AI. Мы обновляем витрину решений, чтобы проще было ориентироваться в API, агентах, автоматизации и инфраструктуре.
