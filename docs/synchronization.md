# Синхронизация публичной витрины

## Назначение

Репозиторий отражает **только публичные данные** каталога Neuromedia: категории, выбранные товары, публичные цены в USD, статус доступности, формат доставки и ссылки на карточки. Источником истины остаётся [neuromedia.cloud](https://neuromedia.cloud/).

## Безопасная архитектура

```text
Админка Neuromedia → отдельный public catalog export (JSON) → GitHub Action → проверка → PR → review → main
```

Экспорт должен быть специальным read-only endpoint или файлом, созданным сервером магазина. Он может содержать **только** поля публичной схемы из `content/meta/catalog.schema.json`.

Никогда не передавать в export или GitHub:

- ключи, токены, пароли и webhook URL;
- данные покупателей, заказы, платежи, адреса и историю действий;
- поставщиков, закупочные цены, маржу и внутренние заметки;
- админские URL, серверные адреса, Docker/БД-конфигурацию;
- исходный код или закрытые файлы магазина.

## Подключение

1. Текущий полный публичный каталог уже доступен на сайте через `https://neuromedia.cloud/api/v1/categories` и `https://neuromedia.cloud/api/v1/products?sort=newest&page=1&per_page=100`; он содержит 81 публичную позицию на момент публикации.
2. Для регулярного production-обновления подготовить выделенный export, например `https://neuromedia.cloud/public/catalog-export.json`, который отдаёт только JSON по утверждённой схеме.
3. В GitHub добавить secret `NEUROMEDIA_PUBLIC_CATALOG_URL` со значением URL выделенного export. Secret скрывает технический путь, хотя endpoint должен оставаться безопасным при раскрытии.
4. Включить workflow **Sync public catalog** вручную или по расписанию. Он создаёт Pull Request, а не пушит изменения напрямую в `main`.
5. Перед merge проверить список изменений: категории, названия, цены, статусы и публичные ссылки.
6. Скрипт `scripts/export_current_public_catalog.py` использован только для первичного безопасного снимка из уже открытого клиентского API; для дальнейшей автоматизации использовать выделенный export.

## Частота

Рекомендуемый режим:

- ежедневная автоматическая проверка;
- ручной запуск после большого обновления каталога;
- merge только после контроля человеком или агентом.

## Локальная проверка

```bash
python3 scripts/sync_public_catalog.py \
  --url 'https://neuromedia.cloud/public/catalog-export.json' \
  --output content/catalog/catalog.ru.json
python3 scripts/validate_catalog.py content/catalog/catalog.ru.json
```

Для запуска без сети можно передать `--input путь/к/export.json`.

## Принципы публикации

- Репозиторий — маркетинговая и справочная витрина, не канал оформления заказа.
- Цена и наличие в GitHub могут отставать; живая карточка товара на сайте всегда приоритетнее.
- Новые языки добавляются отдельными каталогами после проверки перевода и фактических данных.
- Если экспорт содержит лишнее поле, секретоподобную строку или URL не с `neuromedia.cloud`, проверка останавливается.
